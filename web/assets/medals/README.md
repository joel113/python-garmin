# Generated medal artwork

These transparent PNGs were created with the built-in image-generation tool for this project. Gold is the original generated artwork; silver and bronze are edits of that original, preserving the composition and teal ribbons. The UI displays them in activity overview badges, details, and map markers. Text labels accompany the icons for accessibility.

The active UI artwork is now `gold-abstract.png`, `silver-abstract.png`, and `bronze-abstract.png`. The earlier detailed artwork is preserved. Map icons are 26 × 30 px, and overview counts appear before the icon, including `1 x`.

## Abstract gold generation prompt

Use case: stylized-concept. Asset type: abstract flat medal PNG icon for a modern sports dashboard, intended to be displayed at just 24 pixels. Generate exactly ONE gold first-place medal. Very simple geometric vector-like artwork: two short dark teal ribbon tabs form an understated V behind a broad flat circular ochre-gold disk. One clean inset pale gold circular ring, a large bold geometric numeral "1" centered in ivory. Strictly flat solid colors, no metal rendering, no gradients, no texture, no 3D, no shadow, no laurels, no ornaments, no shine, no realistic fabric. Abstract Swiss graphic design, balanced bold shapes, clean sharp edges. Center the icon on a square transparent canvas, fill 85 percent of the canvas, leave clean equal margins. True transparent background. No text except "1", no watermark or logo. The result should look like a crisp minimal app icon, not a photograph of a medal.

Change the ochre-gold disk to cool slate silver, the inset ring to pale silver-white, and replace numeral "1" with numeral "2" of the same size and heavy geometric sans-serif weight, using bright ivory-white. ## Gold generation prompt

Use case: stylized-concept. Asset type: transparent PNG UI medal icon for a personal cycling and running tracker. Create ONE centered gold first-place medal, front-facing, square canvas. Design: a broad circular warm gold medallion with a crisp beveled rim, restrained engraved laurel branches framing a large clearly readable embossed numeral "1", and two short elegant deep teal ribbon folds extending from the top. Polished contemporary sports award icon, softly dimensional metal and enamel, clean silhouette, restrained highlights, beautifully crafted but simple enough to read at 28 to 40 pixels. Medal occupies approximately 85 percent of canvas, equal safe margins, no cropping. Palette: amber gold, warm champagne highlights, deep teal ribbon. Real transparent background, no ground plane, no surrounding decoration, no labels outside medal, no watermark, no logo. This will be the first icon in a matching gold silver bronze set; keep the layout simple and reproducible.

Replace the embossed numeral "1" with a similarly large embossed numeral "2" in the same central position. Keep the deep teal ribbon fabric unchanged. No other text, no new decorative elements, no logo or watermark. Output a single transparent silver medal icon.
